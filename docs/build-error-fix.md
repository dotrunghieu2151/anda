# Fixing "multiple rules generate" Build Error

## Error Message
```
ninja: error: CMakeFiles/impl-Debug.ninja:293: multiple rules generate src/slint_generated_app-window_1.cpp
```

## Cause
This error occurs when CMake/Ninja detects that the same file is being generated by multiple build rules. This is typically caused by a **stale build cache**.

## Solution

### Step 1: Clean Build Directory
Delete or clean your build directory:
- **Windows**: Delete `.build/windows-clang` folder
- **Or use CMake**: `cmake --build . --target clean`

### Step 2: Reconfigure CMake
Reconfigure your CMake project:
- In VS Code: Use CMake extension's "Configure" command
- Or manually: `cmake -B .build/windows-clang -S .`

### Step 3: Rebuild
Rebuild the project:
- In VS Code: Use CMake extension's "Build" command
- Or manually: `cmake --build .build/windows-clang`

## Prevention
- Always clean build directory when:
  - Adding/removing Slint files from `slint_target_sources`
  - Changing CMake configuration significantly
  - After pulling changes that modify CMakeLists.txt

## Alternative: Verify File Listings
If cleaning doesn't work, verify that:
1. Each `.slint` file is listed only **once** in `slint_target_sources`
2. No duplicate `slint_target_sources` calls exist
3. Files aren't being included through multiple CMakeLists.txt files
